# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. In short: be respectful, assume good faith, and keep disagreements about the work. Reports of unacceptable behaviour can be sent to the maintainers through GitHub's private vulnerability reporting on this repository, which reaches the same people; they will be handled in confidence.
